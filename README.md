**Genbit-Game-2D** is an upcoming 2D roguelike game. 

---

## 📖 About the Project
Genbit-Game-2D is a 2D roguelike adventure. Players explore procedurally generated levels, gather resources, and fight enemies. The project is currently in the active development phase.

## ⚙️ Requirements & Getting Started (For Team Members)
Follow these instructions to set up the project on your local machine and avoid repository conflicts.

1. Download and install **Godot Engine** (make sure to use the exact 4.x version agreed upon by the team).
2. Clone the repository to your local drive:
   `git clone https://github.com/blokerx/Genbit-Game-2D.git`
3. Open Godot, click **Import**, locate the project folder, and select the `project.godot` file.
4. Make sure your editor respects the formatting rules defined in the `.editorconfig` file.

## 📂 Project Structure
A quick guide to keeping the repository organized:

* `/assets/` - Main game assets.
  * `/audio/` - Sound effects and music (e.g., `main_menu/rougelike_main_menu_ambience.wav`).
  * `/sprites/` - 2D graphics, characters, and backgrounds.
* `/scenes/` - Saved Godot scenes (`.tscn`).
* `/scripts/` - Source code (GDScript / C#).
* `/.gitignore` and `/.gitattributes` - Git configuration files. Do not modify without consulting the team.
